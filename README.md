# EECS 1011F — Procedural Programming and Mechatronics

This repository is a collection of my work for **EECS 1011F: Procedural Programming and Mechatronics** at York University during the Fall 2026 semester.

The repository contains coursework completed throughout the course, including assignments, laboratory work, projects, and other programming exercises.

## Course

**Course:** EECS 1011F — Procedural Programming and Mechatronics
**Semester:** Fall 2026
