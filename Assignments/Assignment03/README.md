# Assignment 03

## Description

This assignment involves creating a 3D isometric drawing of a given object using MATLAB. The objective is to understand the concepts of 3D plotting, vertex and face definitions, and how to manipulate the view of a 3D plot to achieve an isometric perspective.

## Contents

- `iso3D.m`: Main script for creating the isometric drawing
- `iso3D_test.m`: Variant implementation of a different method to create the isometric drawing
- `iso3D_original.m`: Original implementation of the isometric drawing
- `vertices.csv`: CSV file containing the vertex coordinates of the 3D object

## Notes

No specific notes are provided for this assignment. The focus is on implementing the 3D plotting functionality and ensuring that the isometric view is correctly applied to the generated plot.
