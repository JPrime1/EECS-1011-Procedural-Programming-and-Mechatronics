# EECS1011F Minor Project

## Project Overview

The EECS1011F minor project is a plant-growing project that uses an Arduino-based Grove board to monitor soil conditions and automatically water a plant when needed. The goal is to combine the procedural programming and mechatronics skills developed in the course with a practical indoor gardening setup.

Students are expected to grow a plant in a pot, monitor the environment using the EECS1011 kit and Arduino hardware, and use MATLAB to control the system. The project is designed to connect hardware, software, and a real-world application in a simple and accessible way.

## Materials Needed

The required materials for this plant setup:

- Arduino/Grove kit
- Pot or container
- Indoor potting soil
- Seeds, a seedling, or a small mature plant
- Watering setup compatible with the Arduino board

## Project Milestones

1. Document the plant setup in a PDF and upload it with a photo and a brief description.
2. Install the required software: Arduino IDE and the MATLAB Support Package for Arduino Hardware.
3. Complete the blinking LED exercise using MATLAB and Arduino.

## Connection to Course Learning

This project introduces students to:

- hardware setup and wiring
- digital output control
- MATLAB communication with Arduino
- automation and sensor-based control
- practical engineering project development
