# Lab 02

## Description

This lab focused on plotting and visualizing mathematical functions in MATLAB. The objective was to generate new graphs based on given functions and observe how different expressions produce different curves and behaviors on a coordinate plane.

This was a straightforward exercise with no major challenge, so the implementation was kept simple and direct. The work involved writing a short MATLAB script to define functions, create sample values, and plot the resulting graphs clearly.

## Contents

- `Lab02_Sec05_JamesPrime.m` — MATLAB script used to plot new graphs from the provided functions.

## Notes

This lab was an introductory plotting exercise designed to reinforce function plotting and graph interpretation in MATLAB. Since there was no challenge component yet, the task was intentionally kept easy to follow and simple in structure.
